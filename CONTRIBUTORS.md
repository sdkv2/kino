# Contributors

Everyone below has signed the [Contributor Licence Agreement](CLA.md). Adding your row **is**
the signature — do it in your first pull request, alongside sign-off (`git commit -s`) on your
commits.

Copy the line, fill it in, keep the list alphabetical by GitHub handle:

```
| [@handle](https://github.com/handle) | Your Name | YYYY-MM-DD |
```

If you are contributing on behalf of an employer, put the company in the Name column
(`Your Name (Acme, Inc.)`) so the record is unambiguous.
